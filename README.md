# 🚀 Sorting Algorithms in Java

This repository contains Java implementations of popular Sorting Algorithms with clean code, easy-to-understand logic, and examples. It is designed for beginners, students, and anyone preparing for coding interviews or learning Data Structures and Algorithms (DSA).

## 📚 Algorithms Included

- ✅ Bubble Sort
- ✅ Selection Sort 
-✅Insertion Sort 
- 🔄 Merge Sort (Coming Soon)
- 🔄 Quick Sort (Coming Soon)
- 🔄 Heap Sort (Coming Soon)

- Java

## 🎯 Features

- Clean and beginner-friendly code
- Step-by-step implementations
- Easy to understand logic
- Suitable for DSA practice and interviews
